# Evessé by Dr. Faria — Skin & Aesthetic Clinic

Website for Evessé (Dr. Faria Khan, Consultant Dermatologist), Karachi — DHA Phase 6 and North Nazimabad.

- Static HTML/CSS/JS, no build step. Deploy the repo root on Vercel.
- Pages: `index.html`, `treatments.html`, `about.html`, `clinics.html`
- WebGL dermascope hero (`assets/js/hero-lens.js`) and Three.js skin cross-section (`assets/js/skin3d.js`, lazy-loaded)
- All images WebP in `assets/img`, videos in `assets/video`, fonts and libraries vendored in `assets/fonts` and `assets/vendor`

Designed & built by [Nexlyr Solutions](https://nexlyr.solutions).
